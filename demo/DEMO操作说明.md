# 招商企业服务与智慧监管平台 · DEMO 操作说明

> 配套版本：系统需求分析说明书 V5.0深化版
> 形态：纯前端高保真交互原型（无需部署后端，离线可运行）
> 数据：演示用模拟数据，非真实企业信息

---

## 一、如何打开

- 直接双击 `demo/index.html`，即可在浏览器中打开（推荐 Chrome / Edge）。
- 打开后先进入**登录页**（与前后端分离版同款背景插画）：输入演示账号 `admin / admin123` 登录进入平台；账号或密码错误提示「用户名或密码错误」。登录态以浏览器 localStorage 持久化，**刷新不丢失**；点击顶栏右侧用户区（二次确认）可退出登录回到登录页。
- 本 DEMO 已将图表库（ECharts）本地化至 `assets/vendor/`，**完全离线运行**，无需联网、无需 API Key。
- 如浏览器对本地文件加载脚本有限制（极少数环境），可在 `demo` 目录启动本地服务：
  - 命令行进入 `demo` 目录，执行 `python -m http.server 8080`，访问 `http://localhost:8080`。

## 二、整体布局

正式商用产品布局：全宽顶部栏（横贯屏幕）+ 下方侧边导航 + 内容区。

| 区域 | 说明 |
| ------ | ------ |
| **全宽顶部栏** | 产品 LOGO 与名称 + 全局搜索框 + 演示模式按钮 + 全屏按钮 + 用户信息 |
| **左侧导航** | 九个页面入口，按「招商总览 / 企业监管 / 招商引资 / 智能应用」四个分组排列（白色侧栏、圆角选中态） |
| **页面标题条** | 内容区顶部，显示当前页面标题（与左侧导航菜单名称一致） |
| **内容区** | 各页面主体，含图表、表格、卡片与页面级 AI 交互按钮 |

顶部栏元素分布（左→右，与界面一致）：

1. 产品 LOGO（七星星标——「企业如星、AI 点亮」）+ 产品名称「招商企业服务与智慧监管平台」（同时为浏览器标签页标题）
2. 全局搜索框（占位文字：搜索企业、政策、项目…）：键入关键词后按**回车**触发全局检索，弹出「搜索结果」对话框，按 **企业 / 招商项目 / 政策** 三类分组展示名称匹配结果（每类最多 8 条，超出时提示剩余条数）；企业行显示风险等级徽标、项目行显示所处阶段、政策行显示发文层级。单击任一匹配行直接跳转——企业进入其画像页；项目跳转招商项目页并**自动筛选定位**到该项目卡片（清单关键词同步填入，蓝底高亮 + 滚动居中）；政策跳转政策服务页并自动筛出该政策卡片高亮定位（均不弹详情抽屉）。跳转后对话框自动关闭；支持 × 按钮、点击遮罩、ESC 三种方式关闭，无匹配时显示空态提示
3. 「▶ 演示模式」按钮（演示进行中变为「■ 停止演示」，按 ESC 或再点一次退出）
4. 「全屏」按钮：对整个应用界面一键全屏投放（所有页面可用，再次点击或 ESC 退出）
5. 分隔线 + 用户头像与名称（admin / 系统管理员），**点击用户区注销**（二次确认后回到登录页）

> 说明：行政区划切换不在顶栏——在「招商驾驶舱」页面顶部的**组织架构**下拉中完成（庆阳市（全市）/ 西峰区等 8 县区），切换后驾驶舱整页数据联动。

> UI 风格：现代 SaaS 设计系统——白色侧边栏 + 蓝紫渐变主色（#2563EB→#6366F1）+ 12px 大圆角卡片 + 多层柔和阴影，风险语义色保持红/橙/黄/蓝四级。

## 三、九大页面与演示要点

  第二行——总营收、固定资产投资、带动就业、纳税总额、亩均税收。均带环比增降箭头，点击可下钻企业概况。
- **年度招商目标完成度卡**：协议投资额与到位资金双口径完成率环，自动比对时序进度（超/欠 N 个百分点）。

- **区县招商业绩榜**：8 县区签约投资额排名 + 年度目标完成率，当前选中区县橙色高亮，点击条形下钻该区县视图。

- **重点企业营收 TOP5 条形图**：营收头部企业一目了然。

- **数据资源接入分布**：11 类数据源（工商/税务/社保/司法/知识产权/生态环境等政务数据 + 水滴信用第三方商业信用数据），体现政务数据 + 商业数据的融合能力。
- **今日运行综述 + 今日行动项**：6 条 AI 运行综述；右侧行动项清单自动从待处置预警、逾期任务、在谈储备、落后区县中生成。
- **全屏模式**：顶栏「全屏」按钮对整个应用界面全屏投放（所有页面通用）；页内另有「⬇ 导出报表」按钮。

### 2. 企业概况

**核心价值：全市企业一库管理，多条件查询一键导出**

- **顶部统计条**（8 项，全市口径固定聚合，不随下方筛选联动，与驾驶舱同源）：企业总数 / 总营收 / 纳税总额 / 带动就业 / 风险企业 / 重点企业 / 本月新增 / 平均履约率。
- **企业名录卡**：标题栏右侧含「⬇ 导出 CSV」按钮；查询区内嵌于浅灰描边框——关键词支持企业名称 / 法定代表人 / 统一社会信用代码（逐字动态筛选，兼容中文输入法组词），风险等级 / 行业 / 区县 / 规模下拉即选即筛；下接明细表 + 分页（每页 20 条）。
- **明细表**：表头点击可按营收 / 纳税 / 员工数 / 风险指数升降序排序；风险等级以红橙黄蓝四色徽标直读；CSV 导出为跨页全量数据。
- 点击任意一行或「查看画像」按钮，钻取至「企业画像」页。

### 3. 企业画像

**核心价值：从总览到穿透式认知，AI 研判可解释可审计**

- **左侧企业列表**（双栏布局）：支持搜索 + 行业、风险等级筛选，滚动时常驻，点击即切换右侧画像。
- **企业头部信息**：企业 LOGO、名称、**8 项基本信息网格**（统一社会信用代码、法定代表人、成立时间、注册资本、企业规模、所属行业、经营状态、注册地址）+ 标签、综合风险指数与等级、「＋ 企业服务」按钮（预填该企业创建服务任务）。
- **六层企业驾驶舱（Tab 切换）**：
  1. **概况**：核心指标 + 招商承诺完成率表（含进度条与完成率）。
  2. **经营状态**：经营/信用状态卡 + 企业动态时间轴。
  3. **经营趋势**：营收/纳税/投资三线趋势图（ECharts）。
  4. **关系网络**：股东结构表（持股比例可视化）。
  5. **企业风险**：各风险维度评分矩阵卡（含权重与四色色阶）。底部两个同风格按钮：「✦ AI风险评估」——点击弹出「AI 风险评估」对话框，模拟智能体真实研判节奏（约 8.6 秒）：三步清单逐步点亮，下方日志逐条流出实时过程（引用该企业统一社会信用代码、营收纳税、信用状态、所属行业/区县、高分维度等真实字段），顶部显示已用时与进度百分比；完成后弹窗内呈现本轮评估报告（评估摘要、八维评分更新表、主要风险点、处置建议、档案值 vs 本次评估对比、置信度与总用时），同时页签矩阵中各维度评分已自动刷新为最新检出值（附 ↑↓ 差异标注与"档案值"对照）——报告仅呈现在弹窗中，卡片只更新指标数据；点「关闭」（或 ×/遮罩/ESC）关闭弹窗，页面保持原视图位置。可再次点击重新评估。「查看风险事件 →」一键跳转该企业的风险事件。
  6. **AI 综合研判**：初始进入显示简版研判面板——含研判摘要、核心优势、关注风险、**数据来源**、**置信度**（右上角胶囊）、**历史研判对比**（上次 vs 本次、变化量）；抽样监测企业默认显示简化提示。底部按钮：「⟳ 重新分析研判」——弹出对话框模拟智能体十一步全面研判（核验基本信息与主体资格 → 解析股权结构与关联网络 → 经营表现与履约水平 → 扫描招投标参与情况 → 盘点知识产权与创新实力 → 客户与供应商结构 → 同业竞争格局 → 所处行业发展环境 → 投融资与信贷状况 → 多维风险敞口 → 生成综合研判结论，约 42 秒），顶部动态逐个展示当前步骤——运行中为旋转圆圈、完成后圆圈变为对勾并稍作停顿再进入下一步骤；下半部分过程日志逐条实时滚动（引用统一社会信用代码、股东及持股、营收纳税、履约率、中标次数与合同金额、专利软著商标、客户销售占比、区域同业排名、行业景气度、银行授信与贷款余额等字段），顶部显示已用时与进度；完成后弹窗内呈现完整报告（关键指标快照、核心优势、关注风险与建议、招投标情况、知识产权情况、客户与供应商结构、同业竞争格局、所处行业分析、投融资与信贷状况、八维评分表、数据来源），页签内研判面板同步动态更新为与弹窗结果一致的完整报告（在简版内容基础上增加关键指标快照、关注风险处置建议、招投标情况、知识产权情况、客户与供应商结构、同业竞争格局、所处行业分析、投融资与信贷状况、八维风险评分等章节），关闭弹窗保持原视图位置；「⬇ 导出报告」——一键生成**文字版 PDF**（矢量文字，可选中、可检索、体积小）并保存到本地：页眉编号与密级标识、企业基本信息表、一至十三章正文（研判摘要/核心优势/关注风险与处置建议/经营与履约概览/股权结构简析/招投标情况/知识产权情况/客户与供应商结构/同业竞争格局/所处行业分析/投融资与信贷状况/八维风险评分/数据来源与研判说明），续页自动带隔页页眉，页脚含平台落款、生成日期与页码；内嵌中文字体子集，完全离线生成。「🖨 打印版」——打开排版化打印视图（A4 页边距、表格不跨页断裂、章节标题不孤行、颜色精确还原），自动唤起打印对话框，可选择“另存为 PDF”。抽样企业也可直接使用以上按钮生成完整报告。
- **AI 政策智能匹配**：基于企业画像自动匹配置顶政策（名称、主管部门、级别），点击任一条直达「政策服务」页并自动打开对应政策详情。

### 4. 风险预警

**核心价值：AI 主动找风险，派发—处置—闭环**

- **统计看板（两行四列）**：第一行为红/橙/黄/蓝四级风险企业数；第二行为风险事件总数、待处置、处置中、已处置（对应事件三态流转：待处置 → 已派发 → 已关闭）。
- **双视图雷达**：左侧平台总风险态势（全市企业加权平均 + 综合指数），右侧选中企业雷达图叠加平台平均值虚线对比，每维度显示差值箭头（↑高/↓低/持平）；右上角下拉可切换对比企业，并可一键跳转画像。
- **维度分布与趋势**：风险维度分布条形图 + 近 30 天风险事件趋势图。
- **筛选**：查询条件（关键词 / 风险等级 / 风险维度 / 状态 / 区县）内嵌于事件清单卡片上部——关键词**逐字动态筛选**（兼容中文输入法组词），下拉选择后自动筛选刷新；无结果时显示空态，可一键「清除筛选」；支持跨页 CSV 导出。
- **风险事件清单**：列为风险等级、事件标题与发现时间、风险维度、涉事企业、状态、操作——涉事企业名可点击跳转企业画像；标题栏提供「＋ 新建风险事件」（手动补录）、「批量派发」、「⬇ 导出」。
- **事件详情抽屉**（点击事件行弹出）：事件信息、事件详情与处置建议。
- **一键派发处置任务**：待处置事件点「派发」（抽屉内为「派发处置」），确认后系统自动生成风险处置任务进入「我的工作台」，事件状态更新为「已派发」——**完整闭环演示**。

### 5. 关系图谱

**核心价值：一张图谱看产业全貌，发现隐性关联、透视风险传导、识别招商线索**

- **全景关系网络**：企业、投资平台（国资）、政府部门、政策、招商线索、外部市场等节点，按 10 大产业类别着色；可拖拽、缩放、聚焦邻接。数据层含 **46 个节点、117 条关系边**（15 家企业 + 6 投资平台 + 8 政府部门 + 10 政策 + 4 招商线索 + 3 外部市场）。
- **图层开关**（卡片右上 6 类可视化开关）：企业、投资平台、政府部门、政策、招商线索、外部市场逐层显隐；叠加**区县视角 / 产业视角**切换（节点按区县或行业着色）。
- **连线语义着色**：区分颜色 × 线型表达关系含义——政策服务（蓝实线）、要素保障（蓝点线）、政府监管（琥珀虚线）、同一法人（橙虚线）、招商线索（绿实线）、投资合作（紫实线）、市场协作（青实线）、产业链（灰实线）。右上「语义着色」开关可随时关闭为统一浅灰线，突出网络骨架。
- **关系类型筛选面板**（卡片左下有 8 类连线分组勾选）：按上述连线语义分组显隐某类关系，与图层/区县筛选叠加，可精确聚焦单一关系。
- **两点路径分析**（卡片右上）：启用选点模式后依次点击两个节点，系统以 BFS 自动求出两者最短关系链路——路径连线绿色加粗高亮、起终点强光晕，浮动窗列出逐跳链路与每一步关系，并可清除或重选，辅助研判"两家企业如何关联""风险如何传导"。
- **风险影响半径**：点击**红色/橙色风险企业**，弹出风险影响半径浮动窗，并高亮其一、二级风险传导链路；风险一级关联企业带 ⚠ 角标；同屏叠加平台均值对比（红色/绿框图例）。
- **招商线索节点**（绿色虚线边框，🏢 在谈意向企业）：与「招商项目 → 线索对接」阶段同源，点击直接跳转该线索项目详情——图谱线索与项目库天然对账。
- **资源缺口标识**：企业节点标签带 🏗（土地缺口）或 💰（资金需求）图标，直观看待补短板。
- **右侧统计栏**：各图层节点数量一览（企业、投资平台、政府部门、政策、招商线索、外部市场）。
- **点击行为**：单击普通企业 → 跳转企业画像；红/橙风险企业 → 弹出风险影响半径（见上）；投资平台/政府部门/政策/外部市场 → 提示说明；招商线索节点 → 跳转招商项目线索详情；**双击任一节点** → 进入"隔离模式"，仅保留该节点与直接邻居及其连线，再次双击该节点或**双击空白**恢复全部。
- **重置视图 / 导出图片**：一键复位布局与全部筛选，或将当前图谱导出为图片。

### 6. 我的工作台

**核心价值：任务驱动，AI 赋能一线**

- **任务统计卡**（8 项，全部由任务数据实时统计）：我的任务 / 待处理 / 进行中 / 已逾期 / 已完成 / 完成率 / 本周新增（近 7 天创建的任务数）/ 负责企业（任务关联的去重企业数）。
- **任务类型**：五类——风险处置、项目跟进、企业服务、政策推送、日常巡检，可按类型筛选；每类任务与对应业务数据关联（如风险处置任务挂接风险事件、项目跟进任务挂接招商项目）。
- **任务清单**：筛选条件（状态/类型/优先级/仅看逾期）内嵌于任务清单卡片上部，与表格同卡展示；下拉选择后**自动筛选刷新**，无需点击查询按钮；列表按状态分组排序（待处理→进行中→已逾期→已完成），组内按优先级、截止日期排列；支持分页与 CSV 导出；筛选无结果时显示空态，可一键「清除筛选」。
- **批量操作**：表头全选框可全选/取消本页任务（部分勾选时呈半选态）；勾选后点「批量完成」，确认后批量标记完成并同步关闭关联风险事件（已完成的任务自动跳过）；未勾选时点击会提示。「⬇ 导出」将当前筛选条件下的全部任务（跨页）导出为 CSV 文件。
- **操作按钮按状态给出下一步动作**：待处理 → 「处理」（打开详情抽屉）；进行中 / 已逾期 → 「完成」（确认后转为已完成并同步关闭风险事件）；所有任务均有「查看」按钮，查看与处理分离。
- **任务详情抽屉**（点击「查看」弹出）：状态/优先级/类型徽标、三步处理进度条、编号 / 截止日期 / 创建与完成时间 / 任务来源 / 关联企业（可跳转画像）/ 任务说明；**项目跟进类任务额外显示关联项目及其当前阶段**（按任务来源编号匹配，无编号时按企业自动回溯）；底部按状态提供「完成任务」快捷操作。
- **处理过程记录**：未完成任务可在详情抽屉内编辑并保存处理过程记录（保存后抽屉保持打开，可连续记录，显示最近记录时间；待处理任务保存记录后自动流转为「进行中」）；已完成任务只读回显记录；清单中有记录的任务标题前带 📝 标识；在抽屉内点「完成任务」会先自动落盘当前编辑内容再走确认。
- **今日待办**：上方展示截止日期为今天（系统日期）的未完成任务，覆盖多种任务类型；点击任一待办项直接打开任务详情抽屉，进入处理流程。旁边还有任务类型分布饼图与最近动态。
- **手动新建任务**：任务清单卡片标题栏「＋ 新建任务」打开表单，填写标题、类型、优先级、关联企业与截止日期后创建；初始状态为「待处理」。当任务类型选为**「项目跟进」**时，表单展开**关联项目**选择框（选项自带各项目当前阶段）并实时显示**项目当前阶段**，选定项目自动带出其关联企业；保存后任务来源记录项目编号。保存后自动清除列表筛选回到第一页，新任务行以蓝底高亮显示并滚动定位。
- **其他页面一键添加入口**：
  - 企业画像页 → 「＋ 企业服务」（预填该企业）。
  - 项目详情抽屉 → 「＋ 跟进项目」（预填项目与企业）。
  - 风险预警页 → 「派发」/「派发处置」（自动生成风险处置任务）。

### 7. 招商项目

**核心价值：项目全链路可视化管理**

- **项目总览**：8 项 KPI（项目总数 / 总投资额 / 签约落地 / 建设推进 / 投产运营 / 达产评价 / 本月对接 / 平均落地周期）+ 阶段漏斗图 + 近 6 月落地趋势图。全部由项目数据实时统计：口径为一企一项目，项目总数与涉及企业数一致且少于企业总数；「本月对接」为最近一条对接记录落在本月的项目数；「平均落地周期」按已签约项目「线索对接→签约落地」关键节点真实计算。
- **筛选**：查询条件（关键词 / 项目阶段 / 所在区县 / 责任单位）内嵌于项目清单卡片上部——关键词**逐字动态筛选**（兼容中文输入法组词），下拉选择后自动筛选刷新；点击漏斗阶段即按阶段筛选；无结果时显示空态，可一键「清除筛选」；支持跨页 CSV 导出。
- **新建项目**：「＋ 新建项目」面向**招商引进新企业**——手动输入拟引进企业全称（不从已有企业中选择），输入过程**实时查重**：名称已存在于企业名单时内联红字提示且无法创建；仅新企业允许建档。同时填写项目名称（留空按"企业名+项目"自动生成）、投资总额（必填）、责任单位、所在区县、所属行业、联系人及**线索对接进展情况**。创建成功后**新企业同步写入企业名单**（企业概况页可查，带"新引进"标签、初始蓝色风险），新项目置顶显示（初始阶段：线索对接，进度 5%，自动生成时间线与对接记录）并以蓝底高亮定位。
- **项目卡片**：项目名称、所属企业、当前阶段徽标、区县与责任单位标签、总投资、当前进度、风险标签、六阶段进度条、最近对接时间。
- **项目详情抽屉**（点击项目弹出）：
  - 基本信息（编号、区县、总投资、责任单位、联系人、风险标签）+ 总进度条。
  - 六阶段进度时间轴（已完成 / 当前 / 未开始）。
  - **进展情况**：六个阶段各自带进展文本框——历史阶段只读回显（✓ 标识），**仅当前阶段可编辑并保存**（✎ 标识，保存后抽屉保持打开、显示最近更新时间），未来阶段显示"未开始"；新建项目时填写的线索对接进展情况会在此回显。
  - 关键节点时间轴（含未来计划节点）。
  - 招商承诺清单。
  - 对接记录列表。
  - 底部操作：「＋ 跟进项目」一键创建项目跟进任务、「关联企业画像」跳转。

### 8. 政策服务

**核心价值：政策一站直达，AI 匹配惠企兑现**

- **顶部统计**（8 项，全部真实统计）：政策总数 / 国家级 / 省级 / 市级，以及年度安排、已兑现金额、总体兑现率、惠及企业——兑现数据与驾驶舱「政策兑现服务」卡同源。
- **左侧政策分类导航**：按类型统计政策数量，点击即筛选；下方「近期新政策」快捷入口。
- **筛选**：关键词（**逐字动态筛选**，兼容中文输入法组词）/ 政策层级 / 发布部门，内嵌于政策列表卡片上部，下拉选择后自动筛选刷新；无结果时显示空态，可一键「清除筛选」；支持跨页 CSV 导出。
- **政策卡片**：层级徽标、类型、发布日期与部门、浏览热度、匹配企业数（按企业画像真实计数）。列表标题栏另有「⟳ 同步政策」（模拟增量拉取上级最新政策）、「✦ AI 智能匹配」、「⬇ 导出」。
- **政策详情抽屉**（点击政策卡片或左侧「近期新政策」弹出）：政策摘要、适用对象、支持方式、申报材料、**AI 智能匹配企业**（基于企业画像自动匹配，点击可跳转画像）；底部当前渲染「关闭」按钮（申报辅导任务的批量创建能力已在代码路径中预留，按钮未启用）。企业画像页的 AI 政策匹配项点击后跳转本页并自动弹出对应政策详情。

### 9. 招商智能体

**核心价值：四大独立智能体，各自维护对话上下文，真实对话式交互**

- 左侧智能体导航：**企业洞察智能体 / 风险研判智能体 / 招商谋划智能体 / 企业服务智能体**四个独立智能体，点击切换。
  - 每个智能体显示最近一条消息预览，一眼看出哪个正在沟通。
- 右侧对话窗口：
  - 每个智能体有独立欢迎语，介绍自身能力定位。
  - **预设问题推荐**：每个智能体下有 3 个典型问题，首次对话时显示，提问后自动收起。
  - **真实对话交互**：用户消息气泡 + AI 思考中动画（三点跳动）+ AI 结构化回答（标题+分段）。
  - **自由输入**：底部输入框支持输入文字提问，回车或点发送。
  - **上下文独立**：四个智能体各自维护对话历史，切换时完整保留各自的问答内容，互不干扰。
- 共 12 个深度定制的对话场景，覆盖企业研判、风险详情、产业链分析、目标企业推荐、政策匹配、诉求处理、月报生成等。

> 注：风险研判智能体预置话术中可能出现「九维风险分析」的口语化表述，与需求说明书第九章风险模型的**八维**口径（经营、财务、司法、信用、招投标、税务、招商履约、知识产权）不同，属智能体话术口径；现场若被问及，可说明平台实际采用八维加权模型、维度权重可配置化调整。

## 四、跨页钻取与闭环路径（DEMO 亮点）

### 风险处置闭环（端到端演示路径）

1. 进入**风险预警**页，在事件清单选中一条红色「待处置」事件
2. 点击行内**「派发」**（或详情抽屉「派发处置」）→ 确认后事件状态更新为「已派发」，系统自动生成风险处置任务
3. 切换到**我的工作台** → 任务清单中出现新生成的风险处置任务（按状态与优先级排序置顶）
4. 打开任务详情 → 保存处理过程记录（待处理自动转「进行中」）→ 点「完成任务」确认后转「已完成」
5. 回到**风险预警**页 → 该事件状态已更新为「已关闭」（事件三态流转：待处置 → 已派发 → 已关闭）

### 企业钻取路径

- 企业概况名录行 / 「查看画像」按钮 → 企业画像页
- 风险预警事件清单中的涉事企业名 → 企业画像页
- 风险预警右雷达「查看企业画像」按钮 → 企业画像页
- 图谱节点（普通企业）→ 点击 → 企业画像页；红/橙风险企业 → 弹出风险影响半径浮动窗（内可跳转画像）；招商线索节点（绿色虚线）→ 点击 → 招商项目线索详情
- 工作台任务详情中的关联企业链接 → 企业画像页
- 项目详情抽屉 → 「关联企业画像」→ 企业画像页
- 政策详情「AI 智能匹配企业」→ 点击 → 企业画像页

### 行政区划下钻

- 驾驶舱区县地图 / 区县招商业绩榜 / 组织架构下拉 → 切换到区县视角，KPI 指标联动更新

### 浏览器历史导航

- 页面切换自动写入浏览器历史：点击**浏览器后退/前进按钮**即可回退/恢复上一页（含风险派发、企业画像、政策详情等跨页钻取路径）。
- 支持 `#/页面名` 直达，如 `index.html#/workbench` 打开即到工作台；无效页面名自动回落驾驶舱。
- 演示模式下的自动翻页不写入历史，避免污染回退记录。
- **移动端适配**：兼容桌面与移动端浏览器。窄屏（≤1024px）下左侧导航收纳为抽屉，点击顶栏 ☰ 打开、点遮罩或任一菜单项收起；≤900px 起双栏布局自动转单列（企业画像、图谱/政策侧栏、AI 智能体等），KPI 网格降列，宽表格支持左右滑动；手机竖屏（≤560px）进一步精简顶栏（隐藏全局搜索框）并加大触控目标。桌面端布局不受影响；图表随窗口/屏幕旋转自动重算尺寸。

## 七、演示边界与说明

- 本 DEMO 为**高保真交互原型**，用于需求评审与领导汇报，不代表生产系统功能完整度。
- AI 结论由**预设规则与话术**生成，稳定可控、可复现，演示效果一致；后续可替换为真实大模型 API。
- 行政区划地图为**示意性轮廓**，正式环境需接入官方标准行政区划矢量数据。
- 全部企业、指标、风险事件均为**模拟样例数据**，仅用于演示。
- 已覆盖需求说明书中最具价值的核心场景；系统管理、AI 管理后台等后台类页面属标准范围外。

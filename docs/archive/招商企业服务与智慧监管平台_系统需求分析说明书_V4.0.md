# 一、项目总览与建设目标

## 一.1 项目背景

为落实庆阳市招商引资提质增效、强化企业全生命周期服务与风险监管的总体要求，建设"招商企业服务与智慧监管平台"。平台以企业为核心、以数据为底座、以 AI 为引擎，实现招商企业从引进、落地、建设到达产的全生命周期管理，以及风险的早发现、早预警、早处置。

DEMO V4 为高保真交互原型，覆盖招商驾驶舱、企业档案、风险预警、项目管理、政策服务、AI 智能体等核心场景，所有数据为模拟样例数据。

## 一.2 项目定位

### 一.2.1 总体定位

平台定位为 **AI 原生的、以企业为核心的、用数据说话的监管与服务一体化平台**——不是"招商系统 + 一个 AI 模块"的简单拼接，而是 AI 能力内嵌于每一个业务环节。

**五个一**：
- 一个企业数据库
- 一套企业数字档案
- 一张产业关系图谱
- 一个风险预警中心
- 一个招商智能驾驶舱

**四大 AI 能力**：
- AI 看企业（企业洞察智能体）
- AI 找风险（风险研判智能体）
- AI 做招商（招商谋划智能体）
- AI 帮政府服务企业（企业服务智能体）

### 一.2.2 核心理念

#### 一.2.2.1 从"人工找信息"向"AI主动发现变化"

AI 持续扫描 120 家企业、11 类数据源的变化，主动生成风险事件、AI 每日综述与行动项，把"人找信息"变成"信息找人"。

#### 一.2.2.2 从"发现问题再监管"向"提前识别风险"

建立八大维度加权风险模型（红 / 橙 / 黄 / 蓝四级，环保风险为预留维度），AI 持续监测经营、财务、司法、信用、招投标、税务、招商履约、知识产权等维度变化，风险事件从发现到派发到处置全程留痕。

#### 一.2.2.3 从"招商完成即结束"向"企业全生命周期服务"

项目管理覆盖**线索对接 → 深度洽谈 → 签约落地 → 建设推进 → 投产运营 → 达产评价**六阶段；政策智能匹配、企业服务任务、招商跟进任务贯穿始终，管到企业达产为止。

## 一.3 建设目标与原则

### 一.3.1 总体目标

建成覆盖庆阳市 8 县区、12 个行业的招商企业服务与智慧监管平台，实现：
- **家底清**：全市 120 家企业一企一档，基本信息、经营、风险、关系全掌握
- **风险明**：八维加权评分模型（环保为预留维度），四级风险分级，事件处置闭环
- **项目实**：招商项目六阶段全生命周期管理，进展随阶段沉淀
- **服务准**：AI 政策智能匹配，精准推送申报辅导
- **决策快**：驾驶舱一屏掌握全局态势，AI 每日综述辅助决策
- **招商智**：AI 智能推荐招商项目，产业链缺口分析指引方向

### 一.3.2 建设原则

#### 一.3.2.1 一企一档
每家企业建立完整数字档案，基本信息、经营指标、风险、关系、政策等数据全面归集。

#### 一.3.2.2 一企一画像
企业 360° 画像，六大 Tab 层层穿透：概况 / 经营状态 / 经营趋势 / 关系网络 / 企业风险 / AI 综合研判。

#### 一.3.2.3 一企一风险
按八大维度（环保为预留）加权计算综合风险指数，红橙黄蓝四级标识，风险事件可追踪可处置。

#### 一.3.2.4 一企一服务
政策智能匹配、任务驱动服务、企业诉求响应，服务过程全程留痕。

#### 一.3.2.5 AI 主动服务
AI 不只是聊天问答，而是嵌入业务流程：主动发现风险、主动生成日报、主动推荐项目、主动匹配政策。

#### 一.3.2.6 数据不重复建设
所有页面指标由同一企业库实时聚合推导——页与页之间数字天然对账，区县合计 = 全市、行业合计 = 全市、事件状态与任务一一对应。

#### 一.3.2.7 业务闭环
三条主线闭环：
- **风险处置闭环**：风险发现 → 一键派发 → 专员处置 → 事件关闭 → 驾驶舱闭环率更新
- **项目推进主线**：项目创建 → 阶段推进 → 跟进任务 → 达产评价
- **政策惠企闭环**：AI 政策匹配 → 推送企业 → 申报辅导任务 → 工作台办理

# 二、用户角色与核心工作台

## 二.1 用户角色

平台面向以下三类核心用户，对应不同的工作台与数据视角：

| 角色 | 核心诉求 | 主要入口 |
| --- | --- | --- |
| **主管领导** | 看全局、看趋势、看风险、看成效 | 招商驾驶舱、风险预警总览、AI 每日综述 |
| **招商部门领导** | 看项目推进、看专员绩效、看政策兑现 | 招商驾驶舱、项目全生命周期、工作台 |
| **招商专员** | 管企业、推项目、办任务、服务企业 | 我的工作台、企业画像、项目详情、政策服务 |

> 注：DEMO V4 原型默认以"系统管理员"视角登录，具备全部功能访问权限；角色切换不在本版本实现范围内。

## 二.2 领导驾驶舱（主管领导视角）

主管领导的核心需求是"一屏掌握全局"，对应**招商驾驶舱**页面。支持全市 / 任一县区视角切换，整页数据联动。

### 二.2.1 顶部工具栏

- 组织架构下拉（全市 / 8 县区切换）
- 当前区域标签（"庆阳市（全市）" 及企业总数标注）
- 导出报表按钮
- 📺 全屏模式切换按钮（ESC 退出）

### 二.2.2 KPI 指标区（10 项，两行五列）

- 第一行：企业总数、重点企业、本月新增、本年新增、风险企业
- 第二行：总营收、固定资产投资、带动就业、纳税总额、亩均税收
- 全部带环比箭头（上升绿色 / 下降橙色）
- **点击下钻**：企业总数 / 风险企业等指标卡点击跳转到企业概况页并自动筛选对应条件

### 二.2.3 趋势分析与目标完成

- **总体运行趋势**：双 Tab 切换——本年度（按月）/ 近五年（按年），营收、纳税、投资柱状 + 就业折线双 Y 轴
- **重点企业营收 TOP5**：横向条形图（按营收降序），企业名双行显示，支持 ECharts tooltip
- **年度招商目标完成度**：双环形图（协议投资额 / 到位资金）+ 时序进度对比（超 / 欠 N 个百分点）
- **招商项目阶段漏斗**：六阶段项目数量漏斗，点击任一阶段下钻项目库（零阶段不跳转，提示"该阶段暂无项目"）

### 二.2.4 区域对标与重点项目

- **全省十四个市州对标**：横向条形图，庆阳市橙色高亮，位列全省第三
- **区县招商业绩榜**：8 县区签约投资额排名 + 年度目标完成率，点击可下钻到对应县区视角
- **重大项目 TOP5**：按协议投资额排序的项目列表（排名 / 项目名 / 区县 · 责任单位 · 阶段进度 / 总投资金额），点击跳转到招商项目页并自动筛选定位高亮（项目清单卡片滚到顶 + 目标卡片蓝底高亮）

### 二.2.5 地图与产业分布

- **区县企业分布热力图**：按庆阳市真实区划绘制的 ECharts map，颜色深浅表示企业数量，点击任一县区切换视角
- **产业分布结构**：12 个行业营收分布环形饼图

### 二.2.6 风险态势

- **风险等级分布**：红橙黄蓝四级柱状图，点击可下钻到风险预警页并按等级筛选
- **处置效率指标**：待处置 / 处置中 / 已处置 / 闭环率 四项
- **近 6 个月预警走势**：迷你面积折线图

### 二.2.7 政策兑现与数据接入

- **政策兑现服务**：已兑现金额 / 总体兑现率 / 惠及企业数 + 进度 TOP3 政策条形
- **数据资源接入分布**：11 类数据源徽章（市场监管、税务、司法、人社、自然资源、生态环境、应急管理、海关、公积金、供水供电、征信平台），每类显示接入数据量

### 二.2.8 AI 能力

- **✦ AI 今日运行综述**：5 条综述由 AI 基于当日数据自动生成（随区县切换动态变化）
- **⚡ 今日行动项**：5 条行动项，从红橙级待派发预警、逾期任务、在谈储备、落后区县中自动提炼

## 二.3 招商专员工作台

招商专员的核心需求是"任务驱动、以办代工"，对应**我的工作台**页面。

### 二.3.1 KPI 指标区（8 项）

我的任务总数、待处理、进行中、已逾期、已完成、完成率、本周新增、负责企业数。

### 二.3.2 今日待办与任务分布

- **今日待办**：截止日期为当日的任务列表（最多 5 条），点击直达任务详情抽屉
- **任务类型分布饼图**：五类任务占比（风险处置、项目跟进、企业服务、政策推送、日常巡检）
- **最近动态流**：任务完成 + 新增风险事件 + 任务创建，按时间轴排序

### 二.3.3 任务清单

**筛选条件（4 项 + 复选框）**：
- 任务状态（全部 / 待处理 / 进行中 / 已完成 / 已逾期）
- 任务类型（5 种类型）
- 优先级（高 / 中 / 低 / 全部）
- "仅看逾期"复选框

**操作按钮**：
- "＋ 新建任务" → 新建任务表单抽屉
- "批量完成"按钮 → 批量完成选中任务，自动同步关闭关联风险事件
- "⬇ 导出" → CSV 导出

**任务列表**：
- 复选框（批量选择，表头全选 / 半选联动）
- 优先级徽章（高 = 红 / 中 = 橙 / 低 = 蓝）
- 任务标题 + 类型标签 + 关联企业名（可点击跳转画像）
- 📝 有处理记录的任务标题前带标识
- 截止日期（逾期则标红 + "逾期 N 天"）
- 任务状态
- 操作按钮：处理（待处理）/ 完成（进行中 / 逾期）/ 查看（全部）
- 按 待处理 → 进行中 → 已逾期 → 已完成 分组，组内按优先级和截止日排列
- 分页（8 条 / 页）

### 二.3.4 任务详情抽屉

- 三步进度时间轴：待处理 → 进行中 → 已完成
- 任务信息：编号、截止时间、创建时间、完成时间、任务来源追溯（风险预警派发 / 业务关联项目 / 手动创建 / 例行安排）
- 关联企业（链接跳转画像）
- 关联项目所处阶段（项目跟进类任务显示）
- 任务描述
- 处理过程记录：进行中的任务可随时编辑保存，保存不关窗、可连续记录；待处理任务首次保存自动流转为"进行中"；已完成任务只读回显

### 二.3.5 新建任务

- 任务标题、类型、优先级、截止日期
- 类型选"项目跟进"时展开关联项目选择框（自带各项目当前阶段）并自动带出企业
- 创建后新任务置顶高亮并滚动到视图

# 三、企业全生命周期档案与画像

## 三.1 企业档案库

### 三.1.1 总体统计

企业概况页顶部 8 项全市统计总览：企业总数、总营收、纳税总额、带动就业、风险企业、重点企业、本月新增、平均履约率——与驾驶舱同源、固定全市口径。

### 三.1.2 企业名录

收录全市 120 家企业（15 家深度建档 + 105 家抽样监测），每家都有完整数字档案。

**筛选条件（5 项）**：
- 关键词搜索（企业名称 / 法人 / 统一社会信用代码），150ms 防抖，输入即筛
- 风险等级筛选（全部 / 重大 / 较高 / 一般 / 关注）
- 行业筛选（12 个行业）
- 区县筛选（8 区县 + 全部）
- 企业规模筛选（大型 / 中型 / 小型 / 微型）
- 兼容中文输入法（compositionstart/end 保护，组词期间不刷新）
- 关键词输入焦点与光标位置记忆（重渲染不中断输入）

**结果表格（6 个可排序列）**：
- 企业名称 + 行业 + 区县
- 规模
- 营收
- 纳税
- 员工数
- 风险等级（四色徽章 + 分数）
- 表头点击切换升/降序，默认按风险降序

**操作与分页**：
- 每行含"查看画像"按钮，行点击进入企业画像页
- 分页：每页 20 条
- CSV 导出（跨页 11 列）：编号、企业名称、统一社会信用代码、法定代表人、行业、区县、规模、营收、纳税、员工数、风险等级
- 空状态 + "清除筛选"按钮

## 三.2 企业 360° 画像

### 三.2.1 总体布局

- **左侧企业列表栏**：企业搜索框（关键词过滤）、行业筛选、风险等级筛选、企业列表（名称 + 规模 + 风险徽章 + 标签）、列表滚动位置记忆（切换企业后保持）
- **右侧详情头部**：企业 Logo + 名称、8 项基本工商信息网格（行业、区县、规模、法定代表人、成立日期、注册资本、统一社会信用代码、经营状态）、企业标签（新引进、重点招商企业等）、综合风险评分 + 等级徽章、"＋企业服务"按钮（一键创建企业服务任务）
- 两栏顶端严格对齐

### 三.2.2 第一层：企业概况

核心指标（营收、纳税、员工、投资、亩均税收等）+ 招商承诺完成率表。

### 三.2.3 第二层：经营状态

经营状态 / 信用状态 + 企业动态时间轴（招商、经营、风险、政策等多类型动态）。

### 三.2.4 第三层：经营趋势

营收 / 纳税 / 投资三线图，按月展示经营走势。

### 三.2.5 第四层：关系网络

股东结构与持股比例展示，直观呈现企业股权关系。

### 三.2.6 第五层：企业风险

- **八维风险矩阵**：维度名 + 权重 + 档案值 + 得分 + 条形图色阶展示
- **「✦ AI 风险评估」按钮**：一键触发弹窗研判——三步研判配合实时滚动的过程日志约 9 秒完成，生成维度对比表 + TOP 风险点 + 处置建议，评估报告在弹窗中生成，关闭弹窗后卡片指标同步刷新
- **「查看风险事件」按钮**：跳转风险预警页并自动筛选该企业相关事件

### 三.2.7 第六层：AI 综合研判

- **简版面板**（初始进入时展示）：研判摘要、核心优势、关注风险、数据来源清单、置信度（85%+）、上次 vs 本次研判对比变化（分数差值与方向）
- **「重新分析研判」弹窗**：模拟智能体十一步全面研判（基本信息核验、股权关系、经营履约、招投标情况、知识产权、客户与供应商、同业竞争格局、所处行业环境、投融资信贷、多维风险敞口、生成结论），总时长约 42 秒
  - 顶部动态逐个展示当前步骤：运行中为蓝色旋转圆圈、完成后变为绿色对勾，稍作停顿（约 0.65s）再进入下一步
  - 下半部分日志框实时滚动显示过程信息（检索类步骤日志更丰富、用时更长）
  - 弹窗固定高度，分析期 flex 布局让日志区撑满剩余空间，观感类似控制台
- **完整报告升级**：研判完成后，页签面板同步动态升级为完整研判报告（与弹窗结果完全同源），在简版基础上增加：关键指标快照、关注风险处置建议、招投标情况（近三年）、知识产权情况、客户与供应商结构、同业竞争格局、所处行业分析、投融资与信贷状况、八维风险评分、历史研判对比、数据来源

# 十一、技术实现与交互设计

## 十一.1 技术实现（DEMO V4）

### 十一.1.1 技术栈

- **纯前端高保真原型**：无后端、无构建步骤、无 CDN 依赖，打开 `index.html` 即可运行
- **ECharts 5**：图表库本地化（`assets/vendor/echarts.min.js`），完全离线可用
- **原生 JavaScript**（ES5 兼容） + CSS3 + HTML5
- **零依赖**：除 ECharts 外无第三方库

### 十一.1.2 模块架构与加载顺序

采用 **IIFE + `window.APP.*` / `window.MOCK` 命名空间**模式，按依赖顺序加载（`index.html` 中顺序引用）：

```
echarts.min.js       图表库（先加载，mock 可能用到 graphic 渐变）
  ↓
mock.js              全部模拟数据（MOCK 命名空间，IIFE）
  ↓
utils.js             工具函数（APP.U 命名空间）
  ↓
state.js             全局状态 + 图表管理 + 渲染器注册（APP.state）
  ↓
components.js        公共组件（APP.Components）
  ↓
pages/*.js           9 个页面模块，各自 registerRenderer
  ↓
app.js               入口：路由、全局绑定、演示模式、全局搜索
```

各页面模块通过 `APP.registerRenderer(pageKey, renderFn)` 自注册，app.js 通过 `APP.renderers[page]()` 调用。

### 十一.1.3 数据生成机制

- **固定随机种子** PRNG（mulberry32 算法，SEED = 20260822）
- 所有企业、项目、事件、任务等均由种子确定性生成
- 每次打开页面数据完全一致，保证演示可重复
- 数据聚合：区县 / 行业 / 风险统计全部从企业库实时 `reduce` 聚合，天然对账
- 动态数据：演示模式中创建的新任务 / 新项目 / 同步的新政策直接修改 MOCK 对象，跨页即时可见

### 十一.1.4 全局状态（state.js）

`window.APP.state` 全局对象，字段包括：
- `page`：当前页面 key
- `ent`：当前查看企业 ID（画像页用）
- `district`：全局区县筛选（`'all'` 或区县 key）
- `dispatched`：风险事件是否已派发（用于演示闭环数统计）
- `filter`：各页面筛选状态（project / enterprise / risk / policy 等）
- `highlightProjectId`：项目页高亮项目 ID（跨页定位用）
- `scrollProjListToTop`：项目页滚动清单到顶部标志（漏斗下钻用）
- `policyId` / `policyLocateOnly`：政策页定位标志（搜索跳转用）
- `liveCharts`：活跃 ECharts 实例数组（切页时统一 dispose）
- `renderers`：页面渲染器注册表
- `demoPlaying` / `demoIndex`：演示模式状态

### 十一.1.6 图表体系

- 统一使用 ECharts 5

- 图表类型：柱状图、折线图、饼图、雷达图、漏斗图、地图（散点+热力）、关系图谱 graph

## 十一.2 界面设计规范

- **整体风格**：现代 SaaS 设计——白色侧边栏 + 蓝紫渐变主色（#2563EB→#6366F1）+ 12px 大圆角卡片 + 多层柔和阴影

## 十一.3 核心交互模式

# 十二、三大业务闭环总结

## 十二.1 风险处置闭环（主线 A）

风险预警页选中红色事件 → 一键派发 → 系统自动生成风险处置任务落入专员工作台 → 专员处理、填写过程记录、完成任务 → 关联风险事件状态自动变为"已关闭" → 驾驶舱"已处置 / 闭环率"随之上升。

## 十二.2 项目推进主线（主线 B）

驾驶舱阶段漏斗 / 重大项目 TOP5 点击下钻项目库 → 打开项目详情抽屉编辑当前阶段进展（保存不关窗）→ "+ 跟进项目"生成跟进任务回到工作台 → 项目推进随阶段沉淀。

## 十二.3 政策惠企闭环（主线 C）

企业画像页"AI 政策智能匹配"点击某条政策 → 直达政策服务页并自动打开该政策详情 → "推送至企业"批量为匹配企业创建申报辅导任务 → 工作台接单办理。
